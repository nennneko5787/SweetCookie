## そのかわり見つかったもの — **ホシノは 5 分で寝る。しかも位相がクライアント起動時刻**

| 時刻 | 姿勢 |
|---|---|
| 0 〜 300.25 | `query.target_x_rotation - 30 - this`（起きている） |
| 301.75 〜 599.2 | **`[-23, -10, 9]` を保持（寝ている）** |

| | 寝始めるタイミング |
|---|---|
| 統合版 | 持ち始めてから 5 分（アニメの時計は再生開始で始まる。§4.1.1） |

アニメーションのとおりで、ずれているのは**時計**。

**per-holder の再生状態の優先度を上げる理由がこれ。** これまで「`anim_time_update` などが
待っている」という抽象的な話だったが、**コーパスで実際に目に見える差**が出た。

- [x] コントローラは**1 フレーム 1 遷移**（統合版と同じ）。前フレームの状態から動く
- [x] `src/main`: `AttachablePlaybacks` — エンティティ ID とスロットで引く。

## 決着 — #0 は合成規則の問題ではなかった（2026-08-02 追記）

**答え: 一人称と三人称では、装着者を動かすアニメーションの集合そのものが違う。**
バニラの `controller.animation.player.root` は視点ごとに状態を持ち、両状態は

## 失敗の記録 — 同じことを 3 回やった

**「誤診して入れた変更は、診断が訂正されても自動では消えない」** を、この単位で 3 回踏んだ。

1. `ON_PLAYER` の X 反転 — 脚が逆の真因は回転の向きだったのに、パリティ議論で入れた反転が残った
2. `looking()` の Y 符号 — 真因は角度規約の Y だったのに、対症の符号反転を先に入れた
3. **合成規則** — 「横へ飛ぶ」の真因は角度規約の Y。それを直した後も「後勝ち」規則を
   再検証せず、**根拠が消えたまま残した**

さらに 3 の後始末で **4 回目**をやりかけた: 「Bedrock の既定は加算合成だから」という
**理屈だけ**で、ユーザーが実機で確認済みの規則を上書きし、シロコが正面を向き、ホシノの首が
飛んだ。SC-180 §4.1 に規則 3 つと画面での見え方を表で残し、
**「理屈で置き換えるな。この規則が外す実際のフレームを持ってこい」**と書いた。

## 効いた進め方

**選択肢で聞く。** 「顔の向きがおかしい」だけでは動けなかったが、
「追従するがずれる／上下が逆／左右が逆／固定」＋「どの視点か」を選んでもらったら、
**一人称のみ・追従はする**の 2 条件が原因を 1 点に絞った（絶対 yaw を渡していた）。
推測 3 回より速い。

**症状ではなく前提を聞く。これがいちばん効いた。**
合成規則は症状の説明を積み上げても決まらず、3 つの規則を行き来した。決めたのは
「**シロコは統合版で副手に置けない**」というユーザーの一言で、これが
*条件が真だと分かっている状態での観測*を作った。「条件が偽だっただけかもしれない」という
逃げ道が消え、後勝ちが観測で確定した。

規則を推論で選んでいる間は、どの規則も目の前のスクリーンショットを説明できてしまう。

**測る道具が届いていないと、バグは構造的に見えない。** 今日 3 つ足した:

```
./gradlew --project-dir core :testkit:survey -Paddons=<rp>,attachable.<識別子>[,first|third]
./gradlew --project-dir core :testkit:survey -Paddons=<rp>,geometry.<名前>[,animation.<名前>]
```

- `attachable.<識別子>` — **視点として**姿勢化する（`scripts.animate` 全部、条件も評価）。
  従来の `geometry.` はアニメ 1 本しか適用できず、合成のバグは原理的に見えなかった
- `UNREADABLE:` 行 — コンパイルできなかった Molang を出す（前からあったのに誰も見ていなかった）
- `AttachableContext` を `core` へ移動 — Minecraft 型を 1 つも持たないのに `src/main` にあり、
  測定器がレンダラと同じ文脈を作れなかった

## これまでの教訓

- **「できない」と書くときは、理由を 1 つ確認しただけで書かない**
- **実行する手段が無い環境はバグを隠す**（NeoForge に `runClient` が無かった）
- **テストがコードと同じ間違いに合意していることがある。**`BoneMatricesTest` の Y の
  アサーションは**二度とも**コードに合意しただけだった
- **恒久的に出る「想定内の警告」を作らない**
- **1 軸で正しい補正は、他の軸の証拠にならない**
