# Lepus

[English](README.md) | [日本語](README.ja.md)

**Minecraft 統合版のアドオンを Java 版で動かす MOD。**

`.mcaddon` / `.mcpack` を読み込み、ビヘイビアパックとリソースパックの両方を Java 版の中で実行します。
カスタムブロック・アイテム・エンティティ（コンポーネントと AI ゴール定義込み）、Bedrock のスケルタル
モデルとアニメーション、Molang、Snowstorm パーティクル、ルートテーブル、レシピ、湧き条件。

| | |
|---|---|
| ローダー | Fabric, NeoForge |
| Minecraft | 26.2, 1.21.11 *(順次追加)* |
| 導入先 | **クライアント・サーバーの両方に必須** |
| 状態 | **プレアルファ。** 実際のアドオンのブロックとアイテムは読み込み・バインド・描画まで動きます。エンティティ・Molang クエリ・パーティクルはまだ動きません。 |

## なぜ作るのか

統合版のアドオンシステムは、いくつかの領域で Java 版のデータパックより素直に表現力が高いです。
120 コンポーネント / 171 AI ゴールの語彙を持つデータ駆動エンティティ、状態機械の乗った本格的な
スケルタルアニメーション、Molang、Snowstorm パーティクルエンジン。

そして [Geyser](https://geysermc.org/) サーバーには統合版プレイヤーが既に接続してきています。
彼らが本来遊ぶはずだったアドオンがそのまま動く方が自然です。
**Geyser はビヘイビアパックを意図的にサポートしません** — 実行には Java サーバー側の改変が必要で、
プロキシにはそれができないからです。Lepus は、その欠けている Java サーバー側です。

## 設計の要点

- **フォーマット解析層は Minecraft に依存しない。**`core/` は `net.minecraft.*` 無しでコンパイル
  されるので、4 万行規模になるアドオン解析コードが数秒でユニットテストでき、全 Minecraft バージョンで
  そのまま共有されます。
- **識別子は割り当てず導出する。**`wizardry:magic_wand` は必ず `lepus:wizardry.magic_wand`
  になります。割り当てテーブルも ID 交渉も、クライアントとサーバーの食い違いも発生しません。
- **統合版と同じで、パックはワールドごとに実行中つけ外しできる。**Bedrock の機能に Java の
  レジストリ枠を一つも割り当てません。アイテムはデータコンポーネントの中だけに、エンティティは
  NBT の中だけに存在し、ブロックは起動時に予約した無名スロットのプールへ実行中にバインドされます
  （割り当てはワールドごとに永続化）。有効化・無効化・並べ替え・更新はすべて次の tick で反映
  されます。再起動が必要なのはブロックプールを広げるときだけで、そのときは必要な数を正確に表示
  します。
- **パックを外してもワールドは壊れない。**ブロックはスロットと状態を保持し、アイテムスタックは
  NBT を保持し、エンティティは無害化されるだけ。すべて「アドオン X が必要」と明示され、パックを
  戻せば無損失で復元されます。ブロックの state 一覧が変わった場合も、設置済みブロックは
  グチャグチャにならず正しく再マッピングされます。
- **カスタムコンテンツはバニラのネットワークレジストリ ID を占有しない。**ワイヤ上はバニラの
  「キャリア」＋名前ベースのサイドバンドとして流れるため、ViaVersion / ViaBackwards 経由でも
  バージョンが一致している時と同一に動作します。

規範的な仕様は [`spec/`](spec/) に、機能カバレッジの自動生成表は
[`docs/compatibility/`](docs/compatibility/) にあります。

## 互換性の追跡

Lepus は他人が決めた仕様を実装するプロジェクトなので、「何が動くか」は主張ではなく明示的に
追跡します。全ての Bedrock feature ID が [`spec/coverage/`](spec/coverage/) に、状態・実装クラス・
忠実度の注記・conformance テストへのリンクと共に登録され、そのリンクが嘘をついていれば CI が落ちます。

## 他 MOD との連携

- **Geyser** — `geyser-api` のカスタムアイテム / ブロック / エンティティイベント経由で変換済み
  コンテンツを登録し、アドオン自身のリソースパック半分を統合版クライアントへ無変換で配信します。
- **ViaVersion / ViaBackwards** — 後付けではなく一級の対応対象です。Lepus が入っている
  クライアントは、Minecraft のバージョンがサーバーと一致していてもいなくても同じ挙動になります。
